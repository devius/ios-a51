# A51 Metal (Chlorophyll over Panfrost), stages 1–2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apple's iOS 16.7 Metal shaders compile for the Mali-G72 on the PC (stage 1), and Chlorophyll's device layer (`air_metal.c`) runs compute, IOSurface and render work on the phone's Mali through Panfrost (stage 2).

**Architecture:** Chlorophyll (MIT) is vendored as `gpu/metal/` at a pinned commit. A Mesa patch adds a host tool `air_bifrost` (AIR → NIR → Bifrost, the Panfrost compiler) and a `GALLIUM_PANFROST` branch in `air_metal.c` that opens Panfrost over our `herodrm` and imports IOSurfaces through `herodrm_surface_import`. Stages 3–5 get their own plan after stage 1's gate.

**Tech Stack:** C (Mesa 25.0.7, NIR, Bifrost compiler, Gallium Panfrost), Python 3 (corpus tool), Objective-C only where Chlorophyll already uses it; host build on Linux (meson/ninja), iOS build in the macOS VM.

**Spec:** `docs/superpowers/specs/2026-10-29-a51-gpu-metal-design.md`

## Global Constraints

- Userland: unmodified iPhone X iOS 16.7.16 (iPhone10,3), **arm64, not arm64e**.
- Mesa 25.0.7 with our Panfrost port (`gpu/mesa/`: `herodrm.c`, `hero_hw.c`); iOS builds in the macOS VM (`tools/a51/host/mac-mesa.sh`).
- Chlorophyll vendored as `gpu/metal/` at commit `787338fc7c29` with its licence (`LICENSE.hackios-userland`) and a `NOTICE.md` saying what we changed.
- No Apple binaries or metallibs in git; tests that need them take a path and skip with a message when it is missing.
- Mali-G72 r0p1: Panfrost gpu id `0x6221` (GPU_ID `0x62210010`), Bifrost arch 6.
- None of Chlorophyll's 9 freedreno/ir3 Mesa patches is applied; only `air-frontend.patch` (the AIR frontend's meson hook) is.
- Device files under `/private/var/a51gpu/` (readable by `mobile`).
- Gate after stage 1: QuartzCore `default.metallib` ≥ 135 of 141 functions through Bifrost.

## Review Focus

1. A metallib function that makes the Bifrost compiler crash (assert/signal) must count as a failure of that function, not end the corpus run — Task 3's `test_compiler_crash_is_a_failure`.
2. An IOSurface whose `bytes_per_row` is larger than `width × bytes-per-pixel` (iOS pads rows to 64 bytes) must import with that pitch, not a packed one — Task 5's `surface_padded_rows`.
3. A GPU job that faults must make `rwa_finish` return an error with a reason, as `herodrm` reports faults since sub-project 2 — Task 4's `compute_fault_reported`.
4. Opening the device twice in one process (QuartzCore and a probe) must not open a second HeroGPU connection that breaks the first — Task 4's `device_open_twice`.
5. A function with function constants is compiled with all constants zero by the host tool, as Chlorophyll's ir3 tool does; the report must say so per function rather than look like real coverage — Task 2's `reports_function_constants`.
